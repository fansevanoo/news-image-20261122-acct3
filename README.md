# Sunday 22 November 2026: The World in One Day (account 3)

A flat-vector broadsheet front page with 35 verified stories from
Sunday 22 November 2026, drawn entirely in PIL code (original
drawings — no AI photos). REGION-LED / newspaper v3 formula: a bold
navy masthead band, 6 stat cards, a region bar, a continuous UTC
timeline, 3 heroes, a region-grouped grid of 10, a large world map
with all 35 stories as numbered dots at true coordinates, an ALSO
list of 22, a DATE CHECK bar, and a date-guarantee footer.

- `build.py` — draws `entry.png` (1024×1024) with Pillow.
- `main.py` — entrypoint: copies `entry.png` to `/output`.
- `entry.png` — the deliverable image.
